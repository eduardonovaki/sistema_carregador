# Sistema de Carregamento

Projeto em C que simula o cálculo de tempo necessário para carregar uma bateria com base na capacidade total e na porcentagem atual.

Desenvolvido para simular um carregamento de carros elétricos, em parceria da GoodWe (empresa parceira FIAP)

## Funcionalidades

* Cálculo da energia restante da bateria
* Estimativa de tempo de carregamento
* Entrada de dados via terminal
* Exibição dos resultados de forma clara

## Tecnologias

* Linguagem C

## Como executar

1. Clone o repositório:

```
git clone http://github.com/eduardonovaki/sistema_carregador
```

2. Acesse a pasta do projeto:

```
cd sistema_carregador
```

3. Compile o código:

```
gcc main.c -o carregador
```

4. Execute o programa:

```
./carregador
```

##  Exemplo de uso

Informe a capacidade da bateria (mAh): 5000
